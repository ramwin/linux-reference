## 一、这里放什么

以后关于这个平台的每个问题都落一条,格式固定:问题 → 外部模型回答 → 内部模型回答 → 差异 → 结论。目的不是攒聊天记录,而是**让两边的判断可对照**:同一个问题,外部模型和内部模型各自怎么答,差在事实、前提还是取舍。

- 一个问题一个文件,编号递增,文件名 `NNNN-短标题.md`,复制 [_TEMPLATE.md](./_TEMPLATE.md) 开始;
- 能被证伪的断言,抽到 [../reviews/pending.md](../reviews/pending.md) 排队等外部校对;
- 正文文档里已经写清楚的,不再抄一遍,只写"指向哪篇 + 本次新增的差异"。

## 三、约定

1. **先问外部,再贴内部**。顺序反了,外部回答会被内部结论锚定,对比就失效了;
2. **内部模型的回答原样贴**,不要替它润色——要对比的正是它的原始判断;
3. **标模型与日期**。内部模型要写清版本号(如果有),外部模型写清厂商与日期、是否联网;
4. **结论写成可执行的一句话**:采纳谁、怎么改、改哪篇文档;
5. 差异归三类:事实错(可裁决)、前提不同(写适用条件)、取舍不同(写成两档方案)。
