# 绿联 NAS 插硬盘柜后的权限控制，以及 ext4 能不能直接插

## 问题

1. 把硬盘柜（多盘位 USB 硬盘柜）插到绿联 NAS 上之后，权限是怎么控制的？
2. 绿联云（UGOS Pro）支持 ext4 硬盘直接插入使用吗？

## 结论速览

| 问题 | 结论 |
| --- | --- |
| 硬盘柜插上后是什么身份 | **外部存储**（外挂存储），自动识别挂载，不是存储池/共享文件夹 |
| ext4 能直接插吗 | **能读**。ext4 在外部存储支持格式列表里，插上就能挂载访问，不用格式化 |
| ext4 能直接当内部存储用吗 | **不能**。跨系统的盘只能挂成外部存储；要变成存储空间必须格式化（数据会没） |
| 权限怎么控制 | 系统级一个总开关：**外部存储访问权限 = 允许使用 / 禁止使用**，只对普通用户生效，管理员始终可访问 |
| 有按用户/按文件夹的细分吗 | **没有**。那套「禁止访问/读写/只读」ACL 是存储空间里**共享文件夹**才有的 |
| 能只读挂载吗 | 只有「内置盘位 + 第三方系统盘」这条路径能选只读/读写；USB 硬盘柜走自动挂载，没有这个选项 |

## 一、硬盘柜插上后，在 UGOS Pro 里算什么

UGOS Pro 把「不属于本机存储池的盘」统一按**外部存储**处理，两条接入路径：

- **USB / Type-C 接入**（绝大多数硬盘柜）：系统自动识别并挂载，不用手动操作。
  挂载后出现在【存储管理 → 外部存储管理】，在【文件管理 → 外部设备】里访问。
- **装在 NAS 硬盘位里、但没被本机初始化过的盘**：要去【存储管理 → 硬盘管理 → HDD/SSD】，
  点硬盘右侧「···」→「使用」→ 选「外部存储」，输入管理员密码确认。

关键点：外部存储**不是**存储空间，也不是共享文件夹。它不能建共享文件夹、不能加快照、
不能组 RAID、不能做存储配额。它的定位就是「把这块盘的文件读出来 / 往里写」。

> 多分区会按分区分别显示。硬件 RAID 的硬盘柜，NAS 只看到柜子做出来的那一个逻辑卷。

## 二、权限到底怎么控制

分四层看，从外到内。

### 2.1 系统层：外部存储访问权限（唯一的总开关）

路径：【存储管理】→【外部存储管理】→ 右上角【高级设置】→「外部存储访问权限」

| 取值 | 效果 |
| --- | --- |
| **允许使用**（默认） | 普通用户可访问并使用外部存储设备，包括查看、读取、写入 |
| **禁止使用** | 普通用户看不到这些设备，文件管理里不显示，**任何途径都访问不了** |

适用范围是「外部存储相关设备」，包括 USB 存储设备和外部存储阵列。

这条规则有两个硬限制：

1. **只对普通用户生效**。管理员（admin 角色）始终拥有外部存储访问权限，不受这个开关影响。
2. **全局一刀切**。没有「A 用户只读、B 用户读写」这种粒度，也没有按目录的粒度。
   要么全给，要么全不给。

### 2.2 设备层：USB 存储设备开关

同一个【高级设置】里还有一个「USB 存储设备」开关：允许使用 / 禁止使用。
关掉之后，U 盘、移动硬盘、SD 卡、TF 卡这类 USB 存储全部接不进来——**对所有用户生效，包括管理员**。

这适合「不想让任何人往 NAS 上插 U 盘」的场景，和上面那条「普通用户能不能访问」是两个维度。

### 2.3 文件系统层：ext4 自带的 POSIX 权限

这一层官方文档没写，但原理上是确定的，值得知道：

- 外部盘是**原样挂载**的，ext4 inode 里的 uid / gid / mode 不会因为插到绿联 NAS 上被改写。
- 所以如果这块盘原来在飞牛 / 群晖 / 某台 Linux 上，文件属于 `uid=1000`，插到绿联上这个
  uid 未必对应 NAS 里的某个用户。走 File Manager（后端是 root）一般能读能写，
  但通过 SSH、Docker bind mount、或者将来做 NFS/SMB 暴露时，就会出现
  owner 对不上、显示 `nobody`、写入 permission denied 的情况。
- 想把权限彻底理顺，只能把数据拷出来，在 NAS 上重新格式化 / 建存储空间，再拷回去。

### 2.4 协议层：为什么 SMB / NFS 那套 ACL 不适用

UGOS Pro 的 SMB / NFS / WebDAV 共享对象是**存储空间里的共享文件夹**，
权限模型是「禁止访问 / 读写 / 只读」，规则是显性权限优先、冲突时禁止访问优先、不冲突时叠加。

外部存储不是共享文件夹，所以：

- 它不进入这套按用户 / 用户组的 ACL；
- 对外部盘的控制，实际就只有 2.1 的总开关，加上你愿不愿意把它通过 Docker 等方式再暴露出去。

想把外部盘的内容按人分权限共享，正确做法是：**把数据搬进存储空间的共享文件夹**，再用 ACL 管人。

## 三、绿联云支持 ext4 直接插入吗

### 支持「直接插入并读取」

外部存储支持的文件系统（官方列表）：

```
btrfs、ext2、ext3、ext4、vfat、exfat、FAT16、FAT32、NTFS、XFS
```

不支持：`HFS+`、`APFS`（macOS 专属）。

所以 ext4 盘插上就能挂成外部存储，文件直接可读，不需要格式化。

### 不支持「直接变成内部存储」

- 官方社区回复：**跨系统的存储盘暂不支持**（指当存储空间用），**仅能挂载作为外部存储使用**；
  「硬盘柜也不行，也算跨系统类型了」。
- 只有原本就是 UGOS Pro 用过的盘，在更换绿联 NAS 硬件时可以直接转内部存储。
- UGOS 切到 UGOS Pro 之后，原来的存储空间也只能作为外部存储挂载读取。

说白了：ext4 是「能读」，不是「能接管」。

### 一个容易忽略的细节：内置盘位的第三方系统盘可以选只读/读写

新版固件（1.17.0.0031+）里，装在 **NAS 硬盘位**中、带第三方系统数据的盘，
在「使用」弹窗里可以选择访问模式：

| 模式 | 效果 |
| --- | --- |
| **只读** | 仅查看和复制文件，不修改硬盘数据 |
| **读写** | 查看、复制、写入、修改、删除 |

注意适用范围：**只对装在 NAS 硬盘位里的盘生效**。USB 硬盘柜不在这条路径上，
走的是自动挂载，没有这个只读/读写选项。如果你的硬盘柜是 USB 接的、又需要写保护，
只能靠硬盘本身的写保护开关，或者把盘拆进 NAS 盘位再用这个模式。

## 四、想让数据「归位」该怎么做

外部盘 → 内部存储，数据不会自己过去，得手动搬：

1. 先把硬盘柜挂成外部存储，确认能读到文件；
2. 在 NAS 上建好存储池 + 存储空间（选 Btrfs 或 ext4）；
3. 在【文件管理】里把外部设备里的数据**复制/移动**到共享文件夹；
4. 校验完整性后，再决定要不要把这块盘格式化后并入存储池。

顺序别反：**先备份再格式化**。格式化不可恢复，而且硬件 RAID 柜还不支持 NAS 直接格式化
（要用柜子自己的管理工具）。

## 五、实战建议

- **重要数据别只放外部盘**。外部存储没有 RAID、没有快照、没有 SMART 联动预警。
- 开了「ext4 延迟配置」能提升写入性能，但**拔盘前必须走【弹出】**，否则可能丢数据。
- 家庭多用户场景：给普通用户设「禁止使用」外部存储，把要共享的内容放进共享文件夹用 ACL 管，
  这样才有只读/读写/禁止访问的区分。
- 硬盘柜如果是硬件 RAID 模式，NAS 只看到一块逻辑盘；想让每块盘单独可见，把柜子设成
  JBOD / 单盘模式。
- 换机器 / 换系统前，先确认盘的来源：UGOS Pro 自己用过的盘可以转内部存储，
  别家系统的盘只能外部存储读。
